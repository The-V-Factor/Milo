Milo v0.4.0 新增应用资源排行榜与磁盘监控，可以进一步查看哪些应用占用资源，以及磁盘容量和读写活动。

- 顶部新增“概览 / 应用 / 磁盘”页面切换，保留 CPU、内存、Swap 和毛玻璃样式设置。
- 应用页分别显示 CPU、内存前 5 名，合并可识别的应用及辅助进程，显示参与统计的进程数。
- CPU 按整机 0–100% 计算；内存显示 footprint 容量与物理内存占比。权限不足或无法归属的进程会明确说明，部分采样项目带 `*`。
- 磁盘页显示启动数据卷的总量、已用与当前可用空间，以及可读取的物理磁盘合计读写速度（包含外置盘，排除 DMG）。
- 应用排行和磁盘速度约每 3 秒在后台刷新，容量约每 30 秒刷新；唤醒、设备变化或计数回退后重新建立基线。

## 指标说明

应用排行仅统计当前用户可读取、可归属的应用进程，系统共享服务可能无法计入。内存 footprint 包含压缩等记账项，不能直接与概览已用内存相加对照。磁盘容量采用 APFS 共享空间口径，不包含潜在可清理空间；磁盘总读写的范围与启动数据卷容量不同。

## 下载与安装

支持 macOS 14+，`Milo-0.4.0-universal.dmg` 同时兼容 Apple Silicon 与 Intel。下载 DMG，打开后将 Milo 拖入 Applications；更新前请先退出旧版 Milo。

本版本采用免费的 ad-hoc 签名，没有 Developer ID 签名，也未经过 Apple 公证。首次打开若被拦截，信任该应用的用户可按 [Apple 操作说明](https://support.apple.com/en-us/102445) 在“系统设置 → 隐私与安全性”中选择“仍要打开”。

可下载同名 `.sha256` 文件核验安装包：

```sh
shasum -a 256 -c Milo-0.4.0-universal.dmg.sha256
```
