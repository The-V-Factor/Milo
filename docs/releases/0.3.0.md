Milo v0.3.0 新增 Swap 交换活动监控，帮助区分“占用了多少交换空间”和“此刻交换有多忙”。

- 内存卡片新增换入 / 换出速度，每秒更新，自动使用 KiB/s 或 MiB/s。
- 新增最近 60 秒的合计交换速度曲线，以及按实际时间加权的 60 秒均值。
- 完整采集 60 秒后显示“交换较少 / 交换活跃 / 交换繁忙”：合计均值达到 10 / 50 MiB/s 时切换提示。
- 提示阈值是试用规则，不是 Apple 官方标准，也不代表内存压力或异常。将鼠标停在 Swap 区域可查看解释，停在曲线上可查看自动缩放范围。
- 启动、唤醒或采样中断后重新累计，避免虚假的交换峰值；小屏幕上的详情面板支持滚动。
- 保留 Swap 已用容量、CPU / 内存指标、透明度调节及日间 / 夜间样式。

## 下载与安装

支持 macOS 14+，`Milo-0.3.0-universal.dmg` 同时兼容 Apple Silicon 与 Intel。下载 DMG，打开后将 Milo 拖入 Applications；更新前请先退出旧版 Milo。

本版本采用免费的 ad-hoc 签名，没有 Developer ID 签名，也未经过 Apple 公证。首次打开若被拦截，信任该应用的用户可按 [Apple 操作说明](https://support.apple.com/en-us/102445) 在“系统设置 → 隐私与安全性”中选择“仍要打开”。

可下载同名 `.sha256` 文件核验安装包：

```sh
shasum -a 256 -c Milo-0.3.0-universal.dmg.sha256
```
