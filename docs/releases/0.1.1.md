## 下载与安装

支持 macOS 14+，同一个 DMG 兼容 Apple Silicon 与 Intel。

下载 `Milo-0.1.1-universal.dmg`，打开后将 Milo 拖入 Applications。更新时先退出正在运行的 Milo，再替换旧版本。

本版本采用免费的 ad-hoc 签名，没有 Developer ID 签名，也未经过 Apple 公证。首次打开若被拦截，信任该应用的用户可按 [Apple 操作说明](https://support.apple.com/en-us/102445) 在“系统设置 → 隐私与安全性”中选择“仍要打开”。

下载同名 `.sha256` 校验文件后，可在下载目录执行：

```sh
shasum -a 256 -c Milo-0.1.1-universal.dmg.sha256
```
