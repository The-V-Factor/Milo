Milo v0.2.0 更新了菜单栏详情面板的 macOS 毛玻璃体验。

- 使用 AppKit 原生毛玻璃材质，适配日间与夜间外观。
- 新增 0–100% 透明度滑杆，拖动时实时调整面板背景强度。
- 新增太阳 / 月亮按钮，可独立切换日间和夜间样式。
- 透明度和样式选择会自动保存。
- CPU、内存指标和趋势图保持不变。

## 下载与安装

支持 macOS 14+，`Milo-0.2.0-universal.dmg` 同时兼容 Apple Silicon 与 Intel。下载 DMG，打开后将 Milo 拖入 Applications；更新前请先退出旧版 Milo。

本版本采用免费的 ad-hoc 签名，没有 Developer ID 签名，也未经过 Apple 公证。首次打开若被拦截，信任该应用的用户可按 [Apple 操作说明](https://support.apple.com/en-us/102445) 在“系统设置 → 隐私与安全性”中选择“仍要打开”。

可下载同名 `.sha256` 文件核验安装包：

```sh
shasum -a 256 -c Milo-0.2.0-universal.dmg.sha256
```
