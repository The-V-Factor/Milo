Milo 的首个版本：一个用 SwiftUI + AppKit 开发的 macOS 菜单栏性能监控工具。

## 功能

- 菜单栏实时显示 CPU 与内存使用率，约每秒更新。
- 悬停查看详情，点击固定面板。
- CPU 用户态、系统态、空闲比例，以及 1 / 5 / 15 分钟平均负载。
- 内存总量、已用、应用、有线、压缩、缓存、Free 与 Swap。
- 最近约一分钟的趋势图；睡眠暂停，唤醒重建采样基线。
- 无第三方依赖，不访问网络，不保存监控历史。

## 下载与安装

需要 macOS 14 或更高版本。`Milo-0.1.0-universal.dmg` 同时支持 Apple Silicon 与 Intel。

1. 下载下方 DMG，双击打开。
2. 将 `Milo.app` 拖入 `Applications`。
3. 从应用程序打开 Milo；它显示在顶部菜单栏，没有主窗口或 Dock 图标。

本版本采用 ad-hoc 本地签名，**没有 Developer ID 签名，也未经过 Apple 公证**。首次打开可能被 macOS 拦截。如你信任该应用，可在尝试打开后前往“系统设置 → 隐私与安全性 → 仍要打开”。操作说明见 [Apple 支持](https://support.apple.com/en-us/102445)。

可下载同名 `.sha256` 文件核验安装包。在下载目录运行：

```sh
shasum -a 256 -c Milo-0.1.0-universal.dmg.sha256
```

## 验证与已知限制

发布流程会先运行指标计算和真实系统采样测试，再构建通用二进制并验证 DMG。首次版本尚未完成完整的图形界面、多系统版本与 Intel 实机验收。内存使用率不代表内存压力，统计值可能与活动监视器略有差异。

登录启动、进程排行、网络与磁盘监控不在本版范围内。相关需求见 #1。
